OPEN Instalar Pack HD y mejoras.exe

Keep this entire folder together: the installer uses the HD pack included in archivos. No third texture package is required.

Choose one of two options:

- I already have the game working: select the folder containing swrots.exe and GameData. Click Install the HD pack and improvements. PAL or USA is detected; the original executable, data, saves and settings are kept. HD follows your current setting; if none existed, it is enabled by default.
- Fresh installation: select JediJosh's v0.4.0 port (ZIP or extracted folder), your PAL or USA Xbox ISO/XISO and a new/empty destination folder. Click Install the game with the HD pack and improvements. Your disc is extracted and the correct regional version is applied with the included HD pack.

There is no need to open the game first. The installer does not run it. When finished, you can open the Configurator, choose mode/language, then open swrots.exe yourself.

You need the original port files and your own disc: they are not included. Do not mix two regions in one folder. To try both, repeat the fresh installation in two different destinations.

OPTIONAL DLSS

You can select its option in the installer. Missing components can be downloaded and their SHA-256 hashes verified. The Lecram neural runtime is a community build; each component keeps its licence. If DLSS fails, the base mod remains installed and can be reviewed in the Configurator.

Configure installed game in the installer opens the configurator for an existing game without reinstalling. You can manage DLSS and use its tools there. DLSS FACIL.bat is still available inside the installed game. If you already have local components, select them in the DLSS wizard.

NEW JEDIJOSH VERSIONS

This package was compiled for SWROTS-PC v0.4.0. If your port has a different version, the installer warns you before changing anything. If you continue, JediJosh's core.dll is replaced with the mod's and backed up: you get the mod, but not that version's additions until the pack is released for it. The HD textures work with any version. The developer kit for rebuilding cores is in fuentes_nucleo/actualizar_jedijosh; its technical guide is not needed to install or play.

BACKUPS AND RESTORATION

Replaced files are backed up under _backups_20261019/mod_sith_FECHA. The installer shows the path. Restore backup in the installer lets you choose the installation and its backup folder (the one containing instalacion.json). Settings and disc data are kept. Fresh installations use a temporary folder first; if they fail before completion, a .sith_preparacion folder may remain for diagnosis.
